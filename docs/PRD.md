# FXPulse 产品需求文档（PRD）

版本：v1.4<br>
状态：多来源比较、计算与历史图表已实现<br>
更新时间：2026-08-05

## 1. 产品概述

FXPulse 是面向香港外币用户的汇率比较、金额换算与历史观察工具。用户选择一个基准币种和目标币种后，可以在统一方向下比较公共市场参考价、Wise 公开中间价、汇丰香港官方 TT 牌价与 18 家香港零售银行公开 TT 汇率，并查看过去 7、15、30、90、365 天的多来源走势、区间高低点与涨跌幅。

产品不提供交易或投资建议。银行列展示公开 TT Buy / TT Sell 指示性牌价，不等于登录后优惠价或最终成交价；实际交易必须以相应服务提供方当次确认页面为准。

## 2. 背景与问题

香港用户在持有、消费或兑换多种外币时，需要反复切换银行 App、Wise 和市场行情工具，难以在一个页面完成以下判断：

- 一个基准币种当前能兑换多少其他候选币种；
- 某一币种对在近期处于区间高位还是低位；
- 7 天、15 天、30 天等不同观察周期的趋势是否一致；
- 数据更新时间、来源和“市场价/银行实际报价”的差异是什么。

## 3. 产品目标

### 3.1 MVP 目标

- 10 秒内完成“选择基准币种 → 比较其他币种 → 查看目标币种走势”的核心路径。
- 覆盖 11 个主要币种：AUD、CAD、CHF、CNY、EUR、GBP、HKD、JPY、NZD、SGD、USD。
- 提供清晰、可核验的数据来源、更新时间、缓存状态和风险提示。
- 支持任意币种对一键反转，例如 `USD/AUD ↔ AUD/USD`，所有来源同步切换方向。
- 提供独立金额计算器，输入金额只更新计算结果，不改变下方按 1 单位展示的报价。
- 某一来源不可用时明确显示归档或暂不可用，不使用其他来源代替。
- 在单独的香港银行 TT 排行中覆盖 18 家可取得公开可比买卖价的零售银行，并保留缺失状态与来源时间。
- 使用 Cloudflare 全球网络低成本运行，支持无服务器扩缩容。
- 建立可被传统搜索引擎及 AI 答案引擎正确理解的内容结构。

### 3.2 成功指标

- 首页汇率数据成功率 ≥ 99.5%。
- 缓存命中时 API P95 响应时间 < 300 ms。
- 移动端 Lighthouse Performance、SEO、Accessibility 均达到 90 分以上。
- 首页到币种趋势详情的点击率 ≥ 25%。
- 数据来源与风险提示在所有报价页可见。

## 4. 目标用户

### 核心用户

- 持有外币或使用香港银行换汇服务的个人客户；
- 持有多种外币、需要观察换汇时点的香港用户；
- 有旅游、留学、跨境消费或海外投资换汇需求的用户。

### 用户任务

1. 我想以 HKD 为基准，快速比较 USD、AUD、GBP 等币种的当前参考汇率。
2. 我想查看 AUD/HKD 过去 7、15、30 天的趋势，判断当前处于近期什么位置。
3. 我想在公共市场、Wise 与汇丰公开 TT 牌价之间比较同方向价差。
4. 我想输入一笔金额，默认按公共市场价计算，也能切换 Wise、汇丰或其他香港银行公开牌价。
5. 我想一键把 AUD/USD 反转为 USD/AUD，而不是自己计算倒数。
6. 我想确认每个来源的更新时间、可用状态，以及它是否等于银行实际成交价。
7. 我想在相同换汇方向下比较香港主要零售银行的公开 TT 牌价，快速找到公开价较优的银行。

## 5. 功能范围

### 5.1 汇率总览

- 默认基准币种为 HKD。
- 用户可在 11 个币种中任选基准币种。
- 列出其余 10 个币种，并在每张卡片中直接并列公共市场、Wise、汇丰公开 TT 三项正向汇率及相对价差。
- 显示币种中文名、英文代码、来源状态；汇率数字必须是卡片中的最高视觉层级。
- 点击任一币种卡片进入对应币种对趋势区域和可索引详情 URL。
- 下方总览始终按 `1 基准币种 = x 目标币种` 展示，不受金额计算器影响。
- 当前目标币种始终排在左上角第一张；反转或重新选择目标币种后立即重排。

### 5.2 双币种金额计算器

- 同时提供换出币种、金额、换入币种和计算结果。
- 默认按公共市场参考价估算，并明确显示所用单位汇率。
- 可选择 Wise、汇丰及 18 家香港银行当前可用公开 TT 汇率；不可用来源保留名称并禁用选择。
- 支持一键反转两种币种；反转后 URL、三源对比、走势图和总览基准同步更新。
- 反转控件必须显示“一键反转”和当前方向文字，且在金额计算器与 `MARKET OVERVIEW` 入口均可见，不能只使用无文字图标。
- 输入金额只更新顶部计算结果，不改变三源单位报价、总览卡片或历史统计。

### 5.3 三来源报价对比

- 同一页面并列展示公共市场参考价、Wise 公开中间价、汇丰公开牌价（TT）。
- 每个来源展示报价、更新时间、提供方、实时/归档/暂不可用状态。
- Wise 与汇丰显示相对公共市场价的百分比差异。
- 汇丰按“客户卖出基准币种、买入目标币种”使用 TT Buy / TT Sell 经 HKD 交叉计算，并展示计算口径。
- 汇丰正反方向分别计算，不把一个方向简单取倒数，从而保留银行买卖价差。
- 缺失来源不展示数字，也不使用公共市场价占位。

### 5.4 香港银行 TT 排行

- 针对当前 BASE/QUOTE 方向固定展示 18 家公开发布可比 TT Buy / TT Sell 的香港零售银行。
- 按 `1 BASE` 可兑换的 QUOTE 数量从高到低排序；数值越高代表同一方向下公开牌价越优。
- 每行显示银行中英文名、汇率、相对公共市场差异、TT 计算口径、采集时间和来源状态。
- 汇丰行由官网匿名接口校准并标记“官方直连”；其余行标记“公开聚合”。
- 缺少某币种或任一买卖侧时保留该行并显示“暂不可用”，不推算或补造。
- 明确 18 家是当前能取得同口径公开 TT 数据的零售银行集合，不等同于香港全部认可机构。

### 5.5 币种对趋势

- URL 规则：`/rates/{base}/{quote}`，币种代码使用小写 canonical URL。
- 支持 7、15、30、90、365 天周期。
- 支持公共市场、Wise、汇丰及 18 家香港银行历史来源多选；默认只选择公共市场。
- 支持折线图与柱状图切换；多来源柱状图以半透明颜色叠层区分，汇率数值不相加。
- 展示当前值、区间高点、区间低点、区间涨跌幅；统计默认使用所选的第一个可用来源。
- 桌面端和移动端均支持图表提示与键盘访问。
- 公共市场在 D1 历史不足时使用机构参考汇率冷启动；Wise 与银行来源只使用 FXPulse 真实归档，数据不足时明确显示“历史积累中”，不借用公共市场曲线。

### 5.6 数据说明与风险提示

- 在首屏标注“三源报价对比”，并说明每一列的数据口径。
- 分别展示每个提供方的原始更新时间，不使用页面请求时间冒充行情时间。
- 显示每个来源的实时、归档或暂不可用状态。
- 明确公开银行牌价不等于登录后优惠价或保证成交价。
- 不展示未经授权的汇丰商标或暗示与汇丰存在官方合作。
- 网页明确显示：使用本站数据须事先取得书面授权，未经授权使用视为侵权；授权使用仍须显著标注 FXPulse 并链接公开仓库。

### 5.7 SEO 与 GEO

- 每个币种对拥有独立可抓取 URL、title、description、canonical 和 Open Graph 元数据。
- 输出 `sitemap.xml`、`robots.txt` 和 `llms.txt`。
- 使用 `WebApplication`、`Dataset`、`FAQPage`、`BreadcrumbList` JSON-LD。
- 页面明确回答“数据是什么、何时更新、如何计算、与银行报价有何不同”。
- 关键事实旁展示来源名称与更新时间，减少 AI 引用时的语义歧义。
- 生成覆盖主要币种对的站点地图；后续增加繁体中文与英文 hreflang。

### 5.8 可用性与无障碍

- 移动端最小点击区域 44 × 44 px。
- 支持键盘操作、清晰焦点状态、减少动态效果偏好。
- 图表同时提供文本统计，不以颜色作为唯一信息载体。
- 数值使用等宽数字，JPY 等币种采用适合的显示精度。

## 6. 数据方案

### 6.1 当前参考价

- MVP 数据源：ExchangeRate-API 的开放端点。
- Worker 固定读取同一份 USD 锚定快照，再计算请求币种的交叉汇率，保证正反方向严格互为倒数。
- API 返回提供方原始更新时间；前端据此显示行情新鲜度。
- 当前开放端点通常按日更新，因此产品文案使用“最新市场参考价”，不宣称逐笔或银行级实时行情。

### 6.2 Wise 中间价

- 使用 Wise 公开货币转换器的 `https://wise.com/rates/live` JSON 响应，无需 Token。
- 页面按当前 BASE/QUOTE 方向实时获取；Cron 每小时保存 USD 与其余币种的双向快照。
- 该公开网页接口不承诺 Wise Platform API 的 SLA，因此保留原始更新时间和 D1 降级状态。

### 6.3 汇丰公开牌价（TT）

- 使用汇丰香港官网匿名 `exchange-rate` JSON，读取各币种的 `ttBuyRt`、`ttSelRt` 与 `lastUpdateDate`。
- BASE 为外币时使用 BASE TT Buy；QUOTE 为外币时使用 QUOTE TT Sell；外币交叉盘经 HKD 计算。
- 页面访问时实时获取，Cron 每 15 分钟保存 110 个有方向的汇丰牌价快照。
- 公开牌价不是登录后个性化报价；公共 Worker 不模拟登录，也不接收 Token、Cookie 或账户资料。

### 6.4 香港银行公开 TT 牌价

- 从 YoYoRate 香港公开比较页读取各行 TT Buy / TT Sell，按需请求当前 BASE 与 QUOTE 的币种页，边缘缓存 5 分钟。
- 外币交叉盘统一使用 `BASE.TT_BUY / QUOTE.TT_SELL` 经 HKD 换算；HKD 单边使用相应 TT Buy 或 TT Sell。
- 当前覆盖 18 家可比零售银行；返回全部银行行数、可用数量、缺失原因、来源链接与观察时间。
- 汇丰行使用官网匿名 JSON 的同方向计算值覆盖聚合值；其他银行不冒充官方直连。
- Cron 每小时只请求 10 个非 HKD 币种页，在内存中推导全部银行可用方向并按 100 条一批写入 D1；页面访问同时补充当前币种对小时快照。

### 6.5 历史参考价

- 冷启动历史：Frankfurter v2，多机构/央行参考汇率混合数据。
- 自建历史：Cloudflare Cron 每 15 分钟采集一次 11 个币种相对 USD 的快照并写入 D1。
- 交叉汇率公式：`base → quote = USD→quote / USD→base`。
- 数据保留 400 天；定时任务自动清理更早数据。
- Wise、汇丰和各银行的有向报价写入 `provider_rate_snapshots`；历史接口按用户选择返回多个真实序列及各自可用状态。

### 6.6 降级策略

- 当前价源不可用时，API 返回明确错误，不生成虚假的“实时”数据。
- Wise 或汇丰不可用时只降级到该来源最近归档，并显示“归档”；没有归档则显示“暂不可用”。
- D1 数据不足时，历史接口回退到 Frankfurter 日频数据。
- 外部历史源不可用时，如 D1 有部分数据则返回部分数据并标注来源；两者均不可用时展示可重试状态。

## 7. 信息架构

- `/`：默认 HKD 汇率总览及 HKD/USD 趋势。
- `/rates/{base}/{quote}`：指定币种对详情，可被搜索引擎索引。
- `/methodology`：数据来源、刷新与计算方法（MVP 内嵌，后续独立页面）。
- `/api/rates`：当前参考汇率。
- `/api/compare`：同方向的公共市场、Wise 和汇丰报价及价差。
- `/api/overview`：指定基准币种对应其余 10 个币种的三源批量报价，用于 `MARKET OVERVIEW`。
- `/api/banks`：当前币种对的 18 家香港银行 TT 排行、可用状态及来源元数据。
- `/api/history`：通过 `sources` 参数返回公共市场、Wise、汇丰或指定银行的多历史序列。
- `/api/currencies`：支持币种元数据。
- `/api/health`：运行状态。

## 8. 非功能需求

- 安全：严格校验币种与周期；API 不接受任意上游 URL；设置 CSP、安全响应头和 CORS 同源策略。
- 性能：当前价边缘缓存 5 分钟，历史日频数据缓存 1 小时，静态资产长缓存。
- 隐私：MVP 不需要账号、不使用 Cookie、不存储用户输入金额，也不接收或保存汇丰登录会话及账户资料。
- 授权：仓库源代码可见但不是开源软件；数据、API、整理结果和源代码的再使用必须遵守私有授权条款及强制署名要求。
- 可观测性：Cloudflare Workers Logs/Analytics；定时采集失败需记录提供方与错误类型。
- 成本：单 Worker + D1；公共市场保存 USD 锚定快照，汇丰保存 110 个有方向牌价以保留买卖价差。
- 可读性：深色主题中的辅助文字保持足够对比度；关键说明不低于 12px，汇率数字不得低于 19px，并为三类来源使用可辨识的颜色与文字标签。

## 9. MVP 验收标准

- 11 个币种均可作为基准币种，且交叉汇率计算正确。
- 所有币种对可一键反转，URL 与全部界面状态同步更新；公共市场正反向互为倒数，汇丰按 TT 买卖方向分别报价。
- 金额输入只改变顶部计算结果，不改变下方单位汇率。
- 计算器默认公共市场，并能在当前币种对下选择所有可用系统来源进行计算。
- 三源无需额外凭据即可自动获取；实时、归档、暂不可用状态及价差计算正确。
- 首页 `MARKET OVERVIEW` 的其余 10 个币种均能同时展示公共市场、Wise 和汇丰公开 TT 三项汇率；不能只显示公共市场价。
- `MARKET OVERVIEW` 当前目标币种始终为左上角第一张，反转后原基准币种成为第一张目标卡。
- `#banks` 固定列出 18 家银行；可用行排序、反向公式、HKD 单边公式、缺失行与汇丰官方校准均正确。
- 7/15/30/90/365 天切换、多来源选择及折线/柱状切换能更新图表和区间统计；银行历史不足时不补造。
- URL 可直接打开并恢复指定币种对。
- 数据源、提供方更新时间和风险提示清晰可见。
- `sitemap.xml`、`robots.txt`、`llms.txt` 和 JSON-LD 可访问且内容正确。
- D1 迁移、Cron、单元测试、类型检查和 Worker dry-run 构建通过。
- Chrome、Safari 移动端及桌面端核心流程可用。
- README、网页和 `LICENSE` 均明确私有授权、事先书面授权及 FXPulse 仓库链接署名要求，仓库中不存在允许自由复制、部署或分发的通用许可文本。

## 10. 后续路线

### Phase 1.1

- 评估 Wise Platform/Affiliate 合作方 API，作为公开网页接口的长期 SLA 替代方案。
- 繁体中文与英文版本、hreflang。
- 收藏币种对和本地偏好。
- 自定义目标汇率提醒（Email/Telegram/Push）。
- 更高频商业行情源适配器，明确区分 mid-market、bid、ask。

### Phase 2

- 合规评审后再考虑商业化、会员提醒及数据导出。

## 11. 明确不做

- 不在 Worker 登录或操作用户的银行账户。
- 不保存或上传登录 Token、Cookie、账户号或完整银行响应。
- 不提供自动交易、下单、投资推荐或收益承诺。
- 不把第三方中间价称为汇丰牌价、成交价或保证可获得的兑换价。
