# FXPulse 产品需求文档（PRD）

版本：v1.1<br>
状态：三源对比开发中<br>
更新时间：2026-08-05

## 1. 产品概述

FXPulse 是面向香港外币存款及汇丰香港 Deposit Plus（高息投资存款）关注者的汇率观察工具。用户选择一个基准币种和目标币种后，可以在统一方向下比较公共市场参考价、Wise 中间价与汇丰 Deposit Plus 现货参考价，并查看过去 7、15、30、90、365 天的走势、区间高低点与涨跌幅。

产品不代替银行报价或提供投资建议。汇丰列只展示经安全采集的 Deposit Plus `exchangeSpotRate`，并与产品的 `conversionRate`、利率和最终成交结果严格区分。用户进行实际交易前必须以汇丰香港网银或 App 当次确认页面及产品文件为准。

## 2. 背景与问题

汇丰香港 Deposit Plus 支持 11 个主要币种，但用户在决定存入币种、挂钩币种及目标转换价之前，需要反复切换银行 App 或其他外汇工具，难以在一个页面完成以下判断：

- 一个基准币种当前能兑换多少其他候选币种；
- 某一币种对在近期处于区间高位还是低位；
- 7 天、15 天、30 天等不同观察周期的趋势是否一致；
- 数据更新时间、来源和“市场价/银行实际报价”的差异是什么。

## 3. 产品目标

### 3.1 MVP 目标

- 10 秒内完成“选择基准币种 → 比较其他币种 → 查看目标币种走势”的核心路径。
- 覆盖 Deposit Plus 当前 11 个可用币种：AUD、CAD、CHF、CNY、EUR、GBP、HKD、JPY、NZD、SGD、USD。
- 提供清晰、可核验的数据来源、更新时间、缓存状态和风险提示。
- 支持任意币种对一键反转，例如 `USD/AUD ↔ AUD/USD`，所有来源同步切换方向。
- 提供独立金额计算器，输入金额只更新计算结果，不改变下方按 1 单位展示的报价。
- 某一来源不可用时明确显示待接入/需更新，不使用其他来源代替。
- 使用 Cloudflare 全球网络低成本运行，支持无服务器扩缩容。
- 建立可被传统搜索引擎及 AI 答案引擎正确理解的内容结构。

### 3.2 成功指标

- 首页汇率数据成功率 ≥ 99.5%。
- 缓存命中时 API P95 响应时间 < 300 ms。
- 移动端 Lighthouse Performance、SEO、Accessibility 均达到 90 分以上。
- 首页到币种趋势详情的点击率 ≥ 25%。
- 数据来源与风险提示在所有报价页可见。

## 4. 目标用户

### 核心用户

- 使用汇丰香港 Deposit Plus 或外币定期存款的个人客户；
- 持有多种外币、需要观察换汇时点的香港用户；
- 有旅游、留学、跨境消费或海外投资换汇需求的用户。

### 用户任务

1. 我想以 HKD 为基准，快速比较 USD、AUD、GBP 等币种的当前参考汇率。
2. 我想查看 AUD/HKD 过去 7、15、30 天的趋势，判断当前处于近期什么位置。
3. 我想在公共市场、Wise 与汇丰 Deposit Plus 之间比较同方向价差。
4. 我想输入一笔金额，估算按公共市场参考价能兑换多少目标币种，但不改变下方单位汇率。
5. 我想一键把 AUD/USD 反转为 USD/AUD，而不是自己计算倒数。
6. 我想确认每个来源的更新时间、可用状态，以及它是否等于银行实际成交价。

## 5. 功能范围

### 5.1 汇率总览

- 默认基准币种为 HKD。
- 用户可在 11 个币种中任选基准币种。
- 列出其余 10 个币种的正向汇率和反向汇率。
- 显示币种中文名、英文代码、更新时间与数据状态。
- 点击任一币种卡片进入对应币种对趋势区域和可索引详情 URL。
- 下方总览始终按 `1 基准币种 = x 目标币种` 展示，不受金额计算器影响。

### 5.2 双币种金额计算器

- 同时提供换出币种、金额、换入币种和计算结果。
- 默认按公共市场参考价估算，并明确显示所用单位汇率。
- 支持一键反转两种币种；反转后 URL、三源对比、走势图和总览基准同步更新。
- 输入金额只更新顶部计算结果，不改变三源单位报价、总览卡片或历史统计。

### 5.3 三来源报价对比

- 同一页面并列展示公共市场参考价、Wise 中间价、汇丰 Deposit Plus 现货参考价。
- 每个来源展示报价、更新时间、提供方、可用/需更新/待接入状态。
- Wise 与汇丰显示相对公共市场价的百分比差异。
- 汇丰口径固定为 `exchangeSpotRate`；`conversionRate` 和 `interestRate` 只作为附加产品字段，不混入现货价比较。
- 缺失来源不展示数字，也不使用公共市场价占位。

### 5.4 币种对趋势

- URL 规则：`/rates/{base}/{quote}`，币种代码使用小写 canonical URL。
- 支持 7、15、30、90、365 天周期。
- 展示折线图、当前值、区间高点、区间低点、区间涨跌幅。
- 桌面端和移动端均支持图表提示与键盘访问。
- D1 有足够快照时优先展示 FXPulse 采集数据；历史不足时使用机构参考汇率补齐。

### 5.5 数据说明与风险提示

- 在首屏标注“三源报价对比”，并说明每一列的数据口径。
- 分别展示每个提供方的原始更新时间，不使用页面请求时间冒充行情时间。
- 显示每个来源的缓存、归档、过期或待接入状态。
- 明确 Deposit Plus 不是定期存款、不受香港存款保障计划保障、并非保本产品。
- 不展示未经授权的汇丰商标或暗示与汇丰存在官方合作。

### 5.6 SEO 与 GEO

- 每个币种对拥有独立可抓取 URL、title、description、canonical 和 Open Graph 元数据。
- 输出 `sitemap.xml`、`robots.txt` 和 `llms.txt`。
- 使用 `WebApplication`、`Dataset`、`FAQPage`、`BreadcrumbList` JSON-LD。
- 页面明确回答“数据是什么、何时更新、如何计算、与银行报价有何不同”。
- 关键事实旁展示来源名称与更新时间，减少 AI 引用时的语义歧义。
- 生成覆盖主要币种对的站点地图；后续增加繁体中文与英文 hreflang。

### 5.7 可用性与无障碍

- 移动端最小点击区域 44 × 44 px。
- 支持键盘操作、清晰焦点状态、减少动态效果偏好。
- 图表同时提供文本统计，不以颜色作为唯一信息载体。
- 数值使用等宽数字，JPY 等币种采用适合的显示精度。

## 6. 数据方案

### 6.1 当前参考价

- MVP 数据源：ExchangeRate-API 的开放端点。
- Worker 固定读取同一份 USD 锚定快照，再计算请求币种的交叉汇率，保证正反方向严格互为倒数。
- API 返回提供方原始更新时间；前端据此显示行情新鲜度。
- 当前开放端点通常按日更新，因此产品文案使用“最新市场参考价”，不宣称逐笔或银行级实时行情。

### 6.2 Wise 中间价

- 使用 Wise 官方 `/v1/rates`，生产环境凭据保存在 Cloudflare Secret `WISE_API_TOKEN`。
- 页面按需获取当前币种对；Cron 每小时保存 USD 基准快照。
- 没有官方凭据时显示“待接入”，不抓取 Wise 网页或使用非公开接口。

### 6.3 汇丰 Deposit Plus 现货参考价

- 登录后的 `/aws/sp/dcd/quote` 依赖用户会话，公共 Worker 不模拟登录、不保存 `dspSession`。
- 用户自有设备仅提取 `exchangeSpotRate` 等白名单字段，通过 `HSBC_INGEST_TOKEN` 保护的接口导入。
- 服务端主动丢弃 Cookie、会话 Token、账户号和其他非白名单字段。
- 报价超过 15 分钟后标记“需更新”，并保留原始时间。

### 6.4 历史参考价

- 冷启动历史：Frankfurter v2，多机构/央行参考汇率混合数据。
- 自建历史：Cloudflare Cron 每 15 分钟采集一次 11 个币种相对 USD 的快照并写入 D1。
- 交叉汇率公式：`base → quote = USD→quote / USD→base`。
- 数据保留 400 天；定时任务自动清理更早数据。

### 6.5 降级策略

- 当前价源不可用时，API 返回明确错误，不生成虚假的“实时”数据。
- Wise 或汇丰不可用时只降级到该来源最近归档，并显示“需更新”；没有归档则显示“待接入”。
- D1 数据不足时，历史接口回退到 Frankfurter 日频数据。
- 外部历史源不可用时，如 D1 有部分数据则返回部分数据并标注来源；两者均不可用时展示可重试状态。

## 7. 信息架构

- `/`：默认 HKD 汇率总览及 HKD/USD 趋势。
- `/rates/{base}/{quote}`：指定币种对详情，可被搜索引擎索引。
- `/methodology`：数据来源、刷新与计算方法（MVP 内嵌，后续独立页面）。
- `/api/rates`：当前参考汇率。
- `/api/compare`：同方向的公共市场、Wise 和汇丰报价及价差。
- `/api/ingest/hsbc`：受 Secret 保护的汇丰白名单行情导入。
- `/api/history`：历史序列。
- `/api/currencies`：支持币种元数据。
- `/api/health`：运行状态。

## 8. 非功能需求

- 安全：严格校验币种与周期；API 不接受任意上游 URL；设置 CSP、安全响应头和 CORS 同源策略。
- 性能：当前价边缘缓存 5 分钟，历史日频数据缓存 1 小时，静态资产长缓存。
- 隐私：MVP 不需要账号、不使用 Cookie、不存储用户输入金额；汇丰导入不接收或保存登录会话及账户资料。
- 可观测性：Cloudflare Workers Logs/Analytics；定时采集失败需记录提供方与错误类型。
- 成本：单 Worker + D1；每 15 分钟约写入 11 条快照，避免为所有 110 个币种对重复写入。

## 9. MVP 验收标准

- 11 个币种均可作为基准币种，且交叉汇率计算正确。
- 所有币种对可一键反转，正向与反向报价互为倒数，URL 同步更新。
- 金额输入只改变顶部计算结果，不改变下方单位汇率。
- 三源对比缺失、过期、可用状态及价差计算正确。
- 首页能展示其余 10 个币种当前参考价和反向价。
- 7/15/30/90/365 天切换能更新图表和区间统计。
- URL 可直接打开并恢复指定币种对。
- 数据源、提供方更新时间和风险提示清晰可见。
- `sitemap.xml`、`robots.txt`、`llms.txt` 和 JSON-LD 可访问且内容正确。
- D1 迁移、Cron、单元测试、类型检查和 Worker dry-run 构建通过。
- Chrome、Safari 移动端及桌面端核心流程可用。

## 10. 后续路线

### Phase 1.1

- 申请 Wise Platform/Affiliate 生产凭据，启用 Wise 官方实时列。
- 完成本地汇丰脱敏采集器，仅上传白名单产品行情。
- 繁体中文与英文版本、hreflang。
- 收藏币种对和本地偏好。
- 自定义目标汇率提醒（Email/Telegram/Push）。
- 更高频商业行情源适配器，明确区分 mid-market、bid、ask。

### Phase 2

- Deposit Plus 观察清单、目标转换价与到期情景计算器。
- 基于用户自填利率/期限的情景对比，不抓取或冒充银行个性化报价。
- 主要宏观事件日历及汇率波动解释。
- 合规评审后再考虑商业化、会员提醒及数据导出。

## 11. 明确不做

- 不在 Worker 登录或操作用户的汇丰账户。
- 不保存或上传 `dspSession`、Cookie、账户号或完整汇丰响应。
- 不提供自动交易、下单、投资推荐或收益承诺。
- 不把第三方中间价称为汇丰牌价、成交价或保证可获得的兑换价。
